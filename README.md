# LEVEL UP ACADEMY

ქართულენოვანი, ერთგვერდიანი სასწავლო ცენტრის საპორტფოლიო დემო. ნათელი, ლურჯი და მუქი ლურჯი ვიზუალური იდენტობა; უცხო ენებისა და პროფესიული უნარების ექვსი დემო მიმართულება.

## მნიშვნელოვანი
გამოგონილი სასწავლო ცენტრი — არ წარმოადგენს მოქმედ ბიზნესს. პროგრამები, მიდგომები და შეფასებები კონცეფციის მაგალითებია. ფასები, ხანგრძლივობები, მასწავლებლები, სერტიფიკაციები და პარტნიორები არ არის მითითებული. ფოტოები საილუსტრაციოა და არ ასახავს ცენტრის რეალურ თანამშრომლებს ან სტუდენტებს.

ტელეფონი, ელფოსტა, მისამართი, სოციალური ქსელები და რუკა დასაზუსტებელია. ინტერფეისში გამოყენებულია ქართული წარწერა „დასაზუსტებელია“; ეს მონაცემები გამოქვეყნებამდე შესავსებია.

## ფუნქციები
- კურსების კატეგორიის ფილტრი;
- მობილური მენიუ და ფიქსირებული რეგისტრაციის ღილაკი;
- კურსის წინასწარი არჩევით რეგისტრაციის დიალოგი;
- ფორმის ქართულენოვანი ვალიდაცია და დემო დადასტურება;
- გასაშლელი კითხვები, კლავიატურის მხარდაჭერა, ხილული ფოკუსი;
- შემცირებული მოძრაობის პარამეტრის მხარდაჭერა;
- ადგილობრივი ფოტოები და ქართული ფონტი — გარე დამოკიდებულებების გარეშე.

ფორმა არ აგზავნის მონაცემებს, არ ასრულებს რეალურ რეგისტრაციას და არ იყენებს ბრაუზერის საცავს. გაგზავნის ან დახურვისას შევსებული ველები იწმინდება. გამოიყენეთ მხოლოდ სატესტო მონაცემები.

## ფაილები
`index.html`, `css/style.css`, `js/script.js`, `assets/images/`, `assets/fonts/`, `CREDITS.md`, `QA.md`, `.nojekyll`.

## ლოკალურად გაშვება
შეგიძლიათ პირდაპირ გახსნათ `index.html`. სერვერისთვის პროექტის საქაღალდეში გაუშვით:

```bash
python3 -m http.server 8000
```

შემდეგ გახსენით `http://localhost:8000`.

## GitHub Pages
1. გახსენით ახალი რეპოზიტორია და ატვირთეთ ZIP-ის შიგთავსი ისე, რომ `index.html` იყოს რეპოზიტორიის ფესვში.
2. გახსენით Settings → Pages.
3. აირჩიეთ Deploy from a branch, `main` და `/ (root)`; შეინახეთ.
4. დაელოდეთ გამოქვეყნებას და გახსენით GitHub-ის მიერ ნაჩვენები მისამართი.

ყველა რესურსის გზა ფარდობითია; საიტი მუშაობს როგორც დომენის ფესვში, ისე რეპოზიტორიის ქვეგზაზე. დამატებითი აწყობა ან პაკეტების დაყენება საჭირო არ არის.

## რეალური ბიზნესისთვის მომზადება
- გადაამოწმეთ და ჩაანაცვლეთ კურსები, პირობები და საკონტაქტო ინფორმაცია;
- `data-placeholder` ღილაკები გადააკეთეთ დადასტურებულ ბმულებად;
- შეცვალეთ დემო ფორმა რეალურ მიღების სისტემაზე მხოლოდ შესაბამისი კონფიდენციალურობის წესების დამატების შემდეგ;
- დემო შეფასებები შეცვალეთ ნებადართული რეალური შეფასებებით ან ამოიღეთ;
- საჭიროა დემო ნიშნულების და `noindex, nofollow` მეტამონაცემის გადახედვა რეალური საიტის გაშვებამდე;
- საბოლოო დომენის მიღების შემდეგ შესაძლებელია `canonical` და `og:url` დამატება. აქ გამოგონილი მისამართები გამოყენებული არ არის.

ტექნოლოგიები: HTML, CSS და Vanilla JavaScript. ფრეიმვორკების, ანალიტიკისა და გარე ბიბლიოთეკების გარეშე.
